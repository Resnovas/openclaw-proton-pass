## config

### commandTimeoutMillis

How long any single pass-cli invocation may take before it is abandoned.

Configurable because the right value depends on the host: an unlocked local
vault answers in milliseconds, while a cold agent session on a contended
server can take seconds. A hung vault call must not pin the Gateway open
indefinitely, so there is always a bound.

**Signature**

```ts
export declare const commandTimeoutMillis: Config.Config<number>
```

**Example**

```ts
import { commandTimeoutMillis } from "@resnovas/opp-config"
import { ConfigProvider, Effect } from "effect"

const read = (env: Record<string, string>) =>
  Effect.runSync(
    commandTimeoutMillis.pipe(Effect.withConfigProvider(ConfigProvider.fromMap(new Map(Object.entries(env)))))
  )

assert.strictEqual(read({}), 60_000)
assert.strictEqual(read({ OPENCLAW_PROTONPASS_TIMEOUT_MS: "5000" }), 5_000)
```
